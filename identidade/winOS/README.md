# winOS - propostas de melhoria da letra W

Arquivos criados:

- `logo-winOS-w-v1.svg` - versão principal recomendada. W com construção mais forte, efeito de dobra e melhor presença visual.
- `logo-winOS-w-v2.svg` - versão com escudo, mais institucional.
- `logo-winOS-w-v3.svg` - versão mais compacta, com W dentro de forma circular.

Base usada:

- Cores preservadas do arquivo encontrado em `identidade-win-os/logo-win-os.svg`:
  - amarelo `#FFD54F`
  - laranja `#FF7A00`
  - vermelho `#B22222`
  - fundo `#0A0A0A`
- Wordmark preservado: `WIN-OS`
- Slogan preservado: `JUNTOS VENCEREMOS`

Recomendação:

Usar `logo-winOS-w-v1.svg` como primeira opção para aprovação, porque melhora o peso da letra W sem mudar totalmente a identidade existente.
